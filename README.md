# 🍃 KONOHA HUD

A Shikamaru-inspired desktop system monitor built with Python and Tkinter for Linux.

## Features

- CPU monitoring
- RAM monitoring
- Storage information
- Network activity
- Live system information
- Custom anime-inspired interface

## Requirements

- Linux
- Python 3
- Tkinter
- psutil
- Pillow

## Installation

Install the dependencies:

```bash
sudo apt install python3 python3-tk python3-pil.imagetk
pip install -r requirements.txt
